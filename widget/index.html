TurnTable 위젯 설치

무료 앱 Scriptable을 이용해 홈 화면과 잠금화면에 지금 듣는 곡의 LP를 띄워요. 위젯을 탭하면 TurnTable이 열려요.

  1. Spotify 대시보드에 주소 하나 추가 (처음 한 번)

    developer.spotify.com/dashboard → TurnTable 앱 → Settings → Edit → Redirect URIs에 아래 주소를 추가하고 Save.

    https://siri010192-afk.github.io/turntableweb/widget-callback.html

  2. App Store에서 Scriptable 설치 (무료)
  3. 스크립트 복사
  4. Scriptable에 붙여 넣기

    Scriptable → 오른쪽 위 + → 빈 화면을 길게 눌러 붙여넣기 → 맨 위 제목을 TurnTable로 바꾸기 → 완료.

  5. Spotify 연결

    Scriptable 목록에서 TurnTable을 눌러 실행 → Spotify 연결 → 로그인 → "Scriptable에서 열겠습니까?"에서 열기 → "연결됐어요"가 나오면 끝.

  6. 홈 화면에 위젯 추가

    홈 화면 빈 곳을 길게 누르기 → 왼쪽 위 편집(또는 +) → Scriptable → 작은 크기 또는 중간 크기 추가 → 추가된 위젯을 길게 눌러 위젯 편집 → Script에서 TurnTable 선택.

  7. 잠금화면에도 추가 (선택)

    잠금화면을 길게 누르기 → 사용자화 → 잠금화면 → 위젯 칸 → Scriptable 원형 또는 가로형 → 위젯을 눌러 Script에서 TurnTable 선택.

위젯은 정지된 그림이에요. 언제 다시 그릴지는 iOS가 정해서, 곡이 바뀐 뒤 몇 분 정도 늦게 바뀔 수 있어요. 판이 돌고 톤암을 움직이는 건 TurnTable 앱에서 할 수 있어요.
